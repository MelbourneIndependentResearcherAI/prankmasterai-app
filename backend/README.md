# PrankMasterAI – Backend

A lightweight Express server that powers the PrankMasterAI chat application.  
Handles incoming chat messages and returns responses to the frontend.

---

## 🚀 Features

- Simple and fast Node.js + Express backend  
- JSON-based POST endpoint for chat messages  
- CORS enabled for cross‑origin frontend communication  
- Clean, production‑ready structure  
- Fully compatible with Render deployment
